# VocabTap

A picture-card communication board for children, being extended to support Akan and Ga.

**Status:** In progress. Built as part of my journey into software engineering and QA.

## Why I'm building this
I have worked with children who have communication needs, and I speak Akan and Ga. Many communication tools don't support Ghanaian languages, so I'm building a simple, accessible one.

## What works now
- [x] Picture cards generated from a JavaScript data array
- [x] Category tabs that filter the cards
- [x] Speak a word or phrase on tap (browser text-to-speech, English)
- [x] Sentence builder mode with Speak and Clear buttons
- [x] Form to add custom cards

## Known issues and next steps
- [ ] Saving custom cards between visits (being fixed)
- [ ] Akan and Ga vocabulary and language toggle
- [ ] Recorded audio for Akan and Ga words
- [ ] Keyboard access: cards need to become buttons
